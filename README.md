# NREL 5 MW 参考风机 · 1:1 数字孪生（Three.js）

以美国国家可再生能源实验室公开的 **NREL 5 MW 参考风机**（原型 REpower 5M）为对象，按原始设计参数做 1:1 米制三维建模。气动、控制、结构动力学和风况都由实时求解的物理模型驱动，不是动画。

- 叶轮 Ø126 m、轮毂高 90 m、额定 5 MW @ 11.4 m/s、转速 6.9–12.1 rpm
- 数据来源：J. Jonkman et al., *Definition of a 5-MW Reference Wind Turbine for Offshore System Development*, **NREL/TP-500-38060**, 2009；IEC 61400-1 Ed.3

## 快速开始

```bash
python -m http.server 8123
```

浏览器打开 <http://localhost:8123>（Three.js 从 unpkg CDN 加载，需要联网）。物理校核脚本：

```bash
node tests/validate.mjs
```

## 建了什么

| 层 | 内容 | 文件 |
|---|---|---|
| 设计参数 | 总体尺寸、17 站位叶片气动分布、质量、传动链、塔筒、DISCON 控制参数 | `js/data/nrel5mw.js` |
| 翼型 | DU40/35/30/25/21、NACA64-618 参数化极曲线，Viterna–Corrigan 失速外推到 ±90° | `js/aero/airfoil.js` |
| 气动 | 叶素动量理论（Ning 残差法 + Prandtl 损失 + Buhl 修正），预计算 Cp/Ct/Cq(λ, β) 表 | `js/aero/bem.js` |
| 控制 | DISCON 基准控制器逐行移植：转速滤波、区域 1/1.5/2/2.5/3 转矩控制、增益调度 PI 变桨 | `js/sim/controller.js` |
| 动力学 | 传动链惯量、塔架一阶模态（含气动阻尼）、变桨速率、高速轴制动、偏航、启停状态机 | `js/sim/turbineSim.js` |
| 风况 | 空气密度（海拔/气温/湿度）、对数律风切变、IEC 正常湍流 + Kaimal 谱、EOG 极端阵风、Rayleigh 年发电量 | `js/sim/atmosphere.js` |
| 叶片几何 | 按弦长/扭角/厚度/变桨轴放样 61.5 m 叶片，着色器实现挥舞弯曲 | `js/model/blade.js` |
| 整机 | 锥形塔筒、机舱罩、机舱内部传动链（主轴/齿轮箱/制动器/发电机/变流器/变压器/偏航驱动）、轮毂与变桨系统、测风系统、航空障碍灯 | `js/model/turbine.js` |
| 环境 | Preetham 物理天空与太阳位置、起伏地形、防护林带、道路、吊装平台、人物与车辆比例参照 | `js/model/environment.js` |
| 流场 | 带风切变、冻结湍流、致动盘诱导、尾流膨胀与旋转的气流迹线；垂直风廓线 | `js/model/flow.js` |
| 图表 | 时序曲线、功率曲线、叶片展向 BEM 分布、Cp–λ 曲线族、坎贝尔图、风电场尾流 | `js/ui/charts.js` |

## 与文献的对比（`node tests/validate.mjs`）

| 指标 | 本模型 | 文献 | 偏差 |
|---|---|---|---|
| 最大 Cp（β=0） | 0.478 | 0.482 | −0.8% |
| 最佳叶尖速比 | 7.50 | 7.55 | −0.7% |
| 8 m/s 电功率 | 1.76 MW | ≈1.78 MW | −0.9% |
| 额定风速 | 11.36 m/s | 11.4 m/s | −0.4% |
| 额定转速 | 12.1 rpm | 12.1 rpm | 0 |
| 额定低速轴转矩 | 4.18 MN·m | 4.18 MN·m | 0 |
| 25 m/s 桨距角 | 23.1° | ≈23.5° | −1.6% |
| 额定推力 | 704 kN | ≈800 kN | −12% |

推力偏低，是因为翼型用了参数化极曲线，没有逐点使用 DU 翼型风洞数据表。动态仿真在层流和 IEC A/B 湍流下都能稳定启动、并网、限功率；大风切出和紧急停机（约 10 s 停转）也都能正确完成。

## 操作

- **左侧**：10 分钟平均风速、风向、湍流等级、地表粗糙度、气温/海拔/湿度（→ 空气密度）、时刻（→ 太阳与昼夜，夜间航空灯同步闪烁），IEC EOG 阵风，自动/手动偏航，正常停机、紧急停机、复位
- **右侧 SCADA**：风、叶轮、传动链、载荷与变形、偏航的实时量；能量流（风功率 → 贝兹极限 → 气动功率 → 电功率）；年发电量、容量系数
- **底部图表**：六个标签页，鼠标悬停可读数
- **视角**：全景 / 叶轮正面 / 人眼视角 / 机舱 / 剖视传动链 / 风电场；“剖视”“部件标注”可显示机舱内部
- **时间倍速**：暂停 / 1× / 3× / 10×（偏航只有 0.3°/s，用 10× 观察对风更方便）；按 `H` 隐藏界面

## 已知简化

- 叶片、塔架只取一阶模态，传动链按刚体处理
- 湍流是单点时间序列加叶轮平均滤波，不是三维湍流箱
- 尾流采用解析模型（流场可视化用致动盘 + 线性扩张，风电场功率用 Jensen 模型），没有做 CFD
- 为了演示方便，监控用的“10 分钟平均风速”在仿真中改用 60 s 时间常数；大风切出后锁定 180 s（仿真时间）
