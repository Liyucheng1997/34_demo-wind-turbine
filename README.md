# 🌬️ 风力发电机交互演示 (Three.js)

一个用 **Three.js** 构建的交互式 3D 风力发电机教学项目，帮助直观理解：

1. 风机如何**根据风向自动调整朝向**（偏航 / Yaw 控制）
2. 风的动能如何**通过叶轮和发电机转化为电能**
3. **发电机电磁感应原理的动画可视化**（旋转磁体 + 定子线圈 + 交流波形）
4. **发电功率的实时可视化**（功率、转速、功率系数）
5. 电力如何**沿输电线送到家庭**（3D 能量脉冲 + 窗户亮灯）
6. 发出的电**大概够多少户家庭使用**

打开就能跑，无需安装任何东西。

## 🚀 快速开始

因为用到了 ES Module 和 CDN，需要通过 **本地服务器**（而不是直接双击）打开，否则浏览器会因 CORS 拦截模块加载。

任选一种方式，在项目根目录执行：

```bash
# 方式 A：Python（几乎都自带）
python -m http.server 8000

# 方式 B：Node
npx serve .

# 方式 C：VS Code 装 "Live Server" 插件，右键 index.html → Open with Live Server
```

然后浏览器访问 <http://localhost:8000>。

> 需要联网：Three.js 通过 unpkg CDN 加载（见 `index.html` 里的 importmap）。

## ⚙️ 背后的物理原理

所有公式都在 [`js/physics.js`](js/physics.js) 里，可单独阅读。

### 1. 风中蕴含的功率

$$P_{wind} = \tfrac{1}{2}\,\rho\,A\,v^3$$

- ρ：空气密度（≈1.225 kg/m³）
- A：扫风面积 = πr²（叶片越长，捕获越多）
- v：风速

⚠️ 关键：功率与风速的 **三次方** 成正比 —— **风速翻倍，能量变成 8 倍**，所以风速是最敏感的因素。

### 2. 功率系数 Cp（能取走多少）

风的能量不可能 100% 被取走。理论上限是 **贝兹极限 (Betz limit) ≈ 0.593**，实际机组约 0.4–0.5。

本项目用分段模型模拟真实控制策略：

| 区间 | 行为 |
|---|---|
| < 切入风速 (3 m/s) | 不发电，Cp = 0 |
| 切入 ~ 额定 (3–12 m/s) | 追求最大 Cp，尽量多取能 |
| 额定 ~ 切出 (12–25 m/s) | **变桨/弃风**，主动降低 Cp，维持恒定额定功率 |
| > 切出 (25 m/s) | 保护性停机，Cp = 0 |

### 3. 实际电功率

$$P_{elec} = P_{wind}\times C_p\times \eta_{generator}\quad(\le 额定功率)$$

发电机+变流器效率 η 取 0.95。

### 4. 偏航对风与余弦损失

机舱要正对来风。若朝向有偏差角 θ，捕获功率按 **cos θ** 衰减。
取消“自动偏航”时手动转动风向，可以看到功率随对风误差下降——这就是偏航系统存在的意义。

### 5. 发电机：机械能怎么变成电（电磁感应）

左下角的 **🔌 发电机原理面板**（见 [`js/generator.js`](js/generator.js)）把机舱里的发电机剖开来演示：

- **中心红/蓝磁体**是转子，随叶轮一起转；
- **外圈蓝色线圈**是定子；
- 磁体旋转时，穿过线圈的磁通量不断变化，根据**法拉第电磁感应定律**就在线圈里感应出电流——线圈随相位明暗闪烁，电流点流向灯泡，灯泡亮度 ∝ 功率；
- 底部的**正弦波**是输出的交流电压（AC），**频率 ∝ 转速、幅值 ∝ 功率**。

> 一句话记忆：**发电机就是“反过来的电动机”**。电动机通电后转动（电→机械），发电机被转动后生电（机械→电），两者是同一套电磁结构。

场景里还有一条从塔基通往房屋的**输电线**，缆上流动的绿色光点表示电力外送，功率越大流得越快越亮，房屋窗户也会随之点亮。

### 6. 叶片转速

$$\text{叶尖速度}=\lambda\cdot v,\quad \omega=\frac{\lambda v}{r},\quad rpm=\frac{60\,\omega}{2\pi}$$

λ 是叶尖速比（最佳约 7）。额定风速以上转速被限制，对应真实机组的限速保护。

### 7. 等效家庭户数

$$\text{年发电量}=P_{elec}(kW)\times 8760\,h$$

除以每户年用电量（默认 **3000 kWh/户**）即得可供户数。仪表盘用 🏠 图标可视化（每个图标代表若干户，鼠标悬停可看比例）。

> 这是教学近似：假设全年都维持当前瞬时功率。真实评估会用“容量系数”（陆上风电约 25–40%）。

```

     └─ rotor        叶轮 ← 绕水平轴自转
         └─ hub + 3×blade
```

## 🔧 可调参数

编辑 [`js/physics.js`](js/physics.js) 顶部的 `TURBINE` 对象即可改成你想研究的机型：

```js
export const TURBINE = {
  rotorRadius: 45,    // 叶轮半径 (m)
  ratedPower: 3000,   // 额定功率 (kW)
  cutIn: 3, rated: 12, cutOut: 25,  // 切入/额定/切出风速
  maxCp: 0.45,        // 实际最大功率系数
  airDensity: 1.225,  // 空气密度
  generatorEff: 0.95, // 发电机效率
  tipSpeedRatio: 7,   // 叶尖速比
};
export const HOUSEHOLD_KWH_PER_YEAR = 3000; // 每户年用电量
```

## 📚 延伸学习方向

- **变桨控制 (Pitch control)**：额定以上如何调整叶片角度弃风
- **容量系数 (Capacity factor)**：把瞬时功率换算成更真实的年发电量
- **尾流效应 (Wake effect)**：风电场中前排风机对后排的影响
- **贝兹极限的推导**：为什么最多只能取走 59.3% 的风能
